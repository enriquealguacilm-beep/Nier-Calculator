NieR Calculator
A small web calculator inspired by the visual style of the NieR video game series.

The project combines a themed interface, responsive background images, custom calculator artwork, and background music to create a more immersive version of a classic calculator exercise.

- Features:
Basic arithmetic operations: addition, subtraction, multiplication, and division.

Clear-screen button.

Error handling for invalid operations and division by zero.

Custom seven-segment display font for the calculator screen.

Responsive background that changes for smaller screens.

Background music that starts after the first user interaction.

Custom calculator design created with image assets and CSS positioning.

- Technologies Used:
HTML5

CSS3

JavaScript

Bootstrap 5


- Purpose:
- 
This project was created to practice JavaScript DOM manipulation, event handling, conditional logic, and basic arithmetic operations. It also focuses on using CSS and visual assets to transform a simple functional exercise into a themed and responsive user interface.
